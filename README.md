# Programación III — Semana 4
Repositorio independiente de la Guía de Trabajo de la Semana 4.

Incluye los ejemplos de inicialización avanzada, cascadas de constructores, métodos de fábrica, Builder, encapsulamiento, `final`, cohesión, validación y el ejemplo integrador `LibroBiblioteca`. También incluye los ejercicios 8.1–8.4 resueltos. La guía exige JDK 21 e IntelliJ IDEA Community. fileciteturn0file0L74-L84

## Abrir en IntelliJ
1. Descomprime el ZIP.
2. Abre la carpeta en IntelliJ IDEA.
3. Marca `src` como Sources Root si IntelliJ no lo detecta.
4. Ejecuta `Main.java`.

No se usa Maven ni Gradle.
